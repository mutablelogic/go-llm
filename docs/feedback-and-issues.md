# Feedback & Issues

## Reporting a bug

Open an issue on [GitHub](https://github.com/mutablelogic/go-llm/issues/new), with:

- what you did, and what happened, and what you expected;
- go-llm's version, and how it runs, such as Docker, or `llm run`;
- the provider, and the model;
- any error, from the web UI, the command line, or the server's log.

Leave out API keys, and anything private, from logs and screenshots.

## Asking for a feature

Open an issue saying what you'd like to do, and why. A feature which the assistant can do with a tool is preferred to one in the web UI.

## Security

go-llm has no authentication yet. Don't run it where others can reach it. Report a security issue privately, from the repository's [Security](https://github.com/mutablelogic/go-llm/security) tab, rather than in a public issue.
